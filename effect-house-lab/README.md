# Effect House 제작 작업

업데이트: 2026-09-06. 양보다 완성도를 우선하며, 게시 전 사용자의 최종 확인을 받는다.

## 현재 결과

**2026-10-02 갱신:** ONE BLINK는 폐기했다. 새 기획은 [PLANNING-2026-10-02.md](PLANNING-2026-10-02.md)를 따른다(1순위: 깜빡하면 온다). Effect House는 한글 사용자 경로에서 실행되지 않아 `C:\Users\Public\EHTest` 영문 경로 복사본으로 실행한다. 아래는 이전 기록이다.

**ONE BLINK — 기억한 별 찾기**를 제작 후보로 선정했다. 1.5초 본 표정을 기억한 뒤 여러 별 사이에서 같은 표정을 찾는 3라운드 게임이다. 기존 직업 룰렛은 기술 테스트 전용이다.

- [직접 플레이](http://127.0.0.1:4173/): 이 PC에서 실행 중인 브라우저 검토본.
- [조사 및 선정 근거](RESEARCH-DECISION-2026-09-06.md): 최근 사용량, 실제 이용자 영상, 반례와 해석의 한계.
- [제작·검증 기록](one-blink/README.md): 실행 방법, 테스트 결과와 남은 작업.
- `one-blink/native/OneBlinkController.ts`: 설치된 Effect House 5.14 SDK 정의로 타입 검사를 통과한 코드.
- `one-blink/native/scene-spec.json`: 씬 조립 설계서. 가져올 수 있는 Effect House 프로젝트 파일은 아니다.

**브라우저 검토본은 작동한다. 네이티브 .ehproj 조립, 엔진 실행, 휴대폰 검수는 아직 완료되지 않았다.** Effect House는 설치됐지만 실행 직후 종료되어 작업이 막혔다. 설치 파일 8,036개 무결성 검사는 전부 통과했다. 실행 로그에 `create DC failed`, 종료 코드 `0xC0000409`가 나타났다. 원인은 확정하지 않았다.

계정 생성은 사용자가 완료했다고 전달했다. 로그인·계정 지역·보상 프로그램 자격은 확인하지 않았다. 공개 게시하지 않았다. 앱이 정상 실행되면 씬 조립 → 엔진/기기 검증 → 최종 검토 순서로 이어간다. 사용자가 파일을 직접 조립하도록 넘기는 계획이 아니다.

## 수익화 기준

이번 효과는 제작 품질과 실제 수요를 검증하는 후보이며 수익이 보장되지 않는다. 프로그램 가입 이전에 게시한 효과는 소급 보상되지 않는다. 한국 지원 여부와 실제 계정 자격은 구분한다. 가입 후에는 별도 신규 효과가 필요하다. [공식 Rewards FAQ](https://effecthouse.tiktok.com/learn/guides/support/faq-effect-creator-rewards)

`tracker.json`에 상태를 기록한다. 유료 광고·유료 에셋·인위적인 사용량 증가는 사용하지 않는다. `TREND-RESEARCH.md`는 초기 조사 이력이며 최신 결정은 위 조사 문서가 우선한다.
